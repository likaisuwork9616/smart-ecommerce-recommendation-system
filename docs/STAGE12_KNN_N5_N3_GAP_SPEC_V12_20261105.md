# Stage 12｜高鄰居低投票與低鄰居高投票的補樣規格

## 兩格母體與歷史排除

V11 完成後，55 個細層中有 44 格已有 V6 成本口徑的樣本。其餘 11 格合計 533 筆查詢。按缺樣格的母體筆數排序，本輪兩格分別有 288 筆與 71 筆，合計 359 筆，占剩餘缺樣母體的 67.4%。[V11 實測與剩餘缺口](STAGE12_KNN_N4_VOTE_BANDS_V11_20261105.md)

重新核對已曝光 validation 的完整 166,897 筆結構名冊，以及 V3、V5／V6、V7、V8、V9、V10、V11 七組已驗名單。七組各有 64、48、34、8、8、8、8 筆，跨組去重後共有 176 個已驗身分。補樣須排除這 176 個身分，即使早期驗算採用不同成本口徑也不重抽。

兩格合計可選 **358 筆**。唯一排除的身分出自 V3。表中的範圍與中位數取自整格母體。「結構投票上界」把商品紀錄最多的至多 500 位合格鄰居的列數加總。第一格每筆都有超過 500 位鄰居，按相似度選前 500 位後，實際投票列數可能低於上界。第二格每筆都少於 500 位鄰居，全部入選，因此實測時投票列數應等於上界。

本階段新增選樣與排名均為 **0 筆**。上述數字描述結構與可選容量，兩格的實際耗時尚待補測。[盤點收據與來源指紋](../reports/stage12/retailrocket_session_knn_v12_gap_inventory_20261105.json)
