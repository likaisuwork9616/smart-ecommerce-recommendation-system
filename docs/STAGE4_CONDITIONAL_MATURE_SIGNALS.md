# Stage 4：固定路線、承諾、核准週與支援量的成熟訊號比較

承接[成熟歷史訊號稽核](STAGE4_MATURE_HISTORY_SIGNAL_AUDIT.md)，本輪沿用核准時點的三個候選，以及原101／時齡102 × colsample 0.8／1.0、11／29／42／73／101五種子的凍結分數。先按完整核准日取`floor(N/10)`，未知答案仍競爭名額，再用各階段當時已知答案定義共同漏報與對照。沒有新增配額、分數、模型載入、重播、fit或主方案改選。

**完成固定條件比較後，本輪仍不指定三候選中的任何一個進單因子訓練。** 精確承諾下，等待組三候選支援充分的漏報只涵蓋3／0／7張，SP→SC三者皆0；SP→RJ近期率差雖在二月呈一致反向差異，其他月份未重現相同均值及排序方向。這是配對覆蓋與證據不足，沒有證明候選無效。

## 事前固定的比較

三個候選的公式、事件時鐘、主賣家及原eligible cohort完全沿用上一輪。70,844筆175欄快取中，原138欄逐值保留。歷史送達時間只是可知時間的代理，缺乏入庫與修訂時鐘；完成歷史也不能代表尚未完成慢件。

| 固定項目 | 本輪規則 |
| --- | --- |
| 主要漏報集合 | 同一身分的全20模型共同漏報，不以相同總數代替相同身分 |
| 主要對照 | 同格所有已知準時件，不按模型分數挑對照 |
| 次要對照 | 同格其他已知延遲件，排除全20共同漏報 |
| 群組 | ALL、R＝SP→RJ、A、RA、R不含A、A不含R、非A、SP→SC及八個R/P/A互斥格；八格構成全體完整分割，重疊邊際不得直接加總 |
| A定義 | 核准當下，主賣家90天未觀測交運待件的等待時齡p90在`(24,72]`小時；不是本訂單已等待24–72小時 |
| 主分層 | 完整州路線×原承諾分箱×週一00:00核准週×候選自身支援分箱 |
| 承諾主分析 | `≤7、(7,14]、(14,21]、(21,30]、>30`日曆天；分箱內仍可能有差異 |
| 承諾敏感度 | 精確整數日曆天，其餘條件、門檻與權重相同 |
| 支援分箱 | 未知key、0、1–4、5–19、20–99、100+；不把未知key當作0筆 |
| seller CDF支援 | seller90；固定完整路線，但候選自身支援不要求路線key已知 |
| seller×route率支援 | joint90，不能拿route邊際支援代替joint |
| route30−90支援 | route30與route90分箱都固定；30天是90天子集，不是獨立樣本 |
| 階段 | 原12phase、各自答案截止，分開保存；只以三個不同開發月檢查月份方向 |
| 五種子 | 另保留各seed自己的四模型共同漏報，重用相同對照；不是五份獨立資料 |

每個候選、群組及對照分別計算三層覆蓋：有有限值漏報及對照各至少1筆；漏報至少3筆且對照至少5筆；再要求候選各本地歷史至少20筆，稱為「支援充分」。這些是事前工作門檻，不是統計檢定或能力保證。所有共同漏報都留在分母，未涵蓋部分互斥拆成訊號缺失、無有限對照、格內樣本少及本地歷史不足。

同格先算漏報均值減對照均值，再按該格有限漏報筆數加權，讓對照標準化到相同組成；另報每格等權的敏感度。CDF乘−1轉為風險方向，其餘乘+1。配對排序率是漏報訊號風險高於同格對照的比例，絕對差≤1e−12同分算半分；同樣按漏報筆數加權，不按配對數加權。配對數不是獨立樣本數，排序率也不是新模型AUC。

二月開發月另保存五個重點群組的所有觀測格，包括零漏報格。其他11phase保留完整摘要、週別與五種子，不合併重複驗證月份。看過稀疏結果後，不放寬路線、週、承諾或支援門檻。

事前的探索篩查要求：兩承諾規格的支援充分漏報各至少20筆、跨至少3個核准週；均值與排序率方向相同，五個seed同向，且在至少兩個不同開發月同向。正向與反向假說分開列出；此旗標不代表顯著性、因果、增量預測力，也不自動選定訓練候選。

## 本輪決定與下一步

暫不指定seller CDF、joint率或近期率差作正式單因子訓練。候選自身歷史不足、相近條件對照不足與方向不一致是不同問題，本輪已分開量化；沒有新增fit或開發召回改善，也沒有藉反向旗標直接翻號、改權重或新增路線名額。

下一步優先稽核**完成歷史對尚未完成慢件的代表性，以及核准週內時間與完成事件組成**，先明列母體、可得時間與缺口。這是釐清本輪訊號可解讀範圍，不把配對門檻放寬到產生正結果。若之後形成單一可測假說，再另凍結101×0.8只加一欄、相同前處理／成熟訓練時鐘、五種子及完整日10%的成對訓練規格；R／A／RA／SC和其他路線代價都要報。這些後續工作尚未執行。

上述代表性與週內組成只是待驗證假說，目前沒有證明它們造成漏報。後續應分開核對當下已成熟、仍待完成與原cohort排除群體的覆蓋，不把事後最終狀態投入當下特徵。

研究主方案仍413TP、開發召回25.15%、歷史下限19.63%；各歷史月30%適用要求未達。原預設RF、原保留測試與Dashboard暫緩規劃維持。
