## 固定四例、八組參照

目標沿用 V54：V48 第 2／3 對投票累加、第 4／5 對正重疊，每例都保留序位 32／33 × R／C 四格，共 16 格。R＝V39 原版，C＝V46 候選。沒有只挑前輪較長的格，也不依本輪名次再篩選。

參照按兩分項 × 兩臂 × 兩序位分成八組，每組包含原六個正式 pair，共 48 個唯一 timer。原順序為第 1／3／5 對 CR、第 2／4／6 對 RC，保留每次的 pair、順序及該臂在對內先／後執行的標記。V47 與兩窗暖機只作來源核對，不放進時間分布；query 外層時間或尾端 commit 也不混入指定分項。

同群的兩個目標共用六值參照。這八組、16 格及其其他五值集合大量重疊，不能當作互相獨立的樣本，也不能跨臂、分項、序位或窗口混合。

## 統計口徑先固定

| 項目 | 定義 |
| --- | --- |
| 六值摘要 | 含目標自身，列最小、中位、最大、最大−最小與未縮放 MAD |
| 中位數 | 排序後偶數取中間兩值平均，奇數取中間值 |
| MAD | `median(abs(x − median(x)))`，不乘校正常數、不當異常門檻 |
| 名次 | 本群六次由長到短，1 為最長；精確同值保留占用的首／末名次，不以四捨五入或容差合併 |
| 計數 | 嚴格小於、等於、嚴格大於目標的個數；合計六，等於含自身 |
| 對中位數 | 目標−本組中位數，以及目標／中位數；中位數為零時倍數為 null |
| 其他五次 | 只排除當前 pair 的一格，再算自己的中位數、MAD、範圍、差與倍數；同群另一個 V54 目標保留 |
| 對五值範圍 | 嚴格低於、範圍內、嚴格高於；等於端點算範圍內 |

「高於其他五次最大值」等價於「本群六次唯一最大值」，不是額外獨立證據。其他五次仍是同一已曝光窗口的留一描述，不能當外部基準或保留驗證。六次中最長不等於統計顯著、異常、尖峰或候選造成。

輸入嚴格限定整數 pair 1–6 與非負有限數字，拒絕布林、缺漏、多餘、字串／浮點 pair key、非有限值及衍生溢位。摘要不修改輸入；中位數避免兩個大有限值相加溢位或極小值過早下溢。
