# Stage 4：固定五種子，單獨比較每棵樹欄位取樣0.8與1.0

前輪[五種子成對實驗](STAGE4_AGE_SEED_STABILITY.md)中，二月時齡102相對101的命中差為+12／+16／−16／−5／+16，平均+4.6、範圍−16到+16；SP→SC卻五個種子都少抓2–4張，等待24–72小時組4退1進。本輪維持相同資料、特徵與種子，只改`colsample_bytree=0.8→1.0`，觀察結果與路線代價是否較一致。

## 訓練前固定條件

| 固定項目 | 規格 |
| --- | --- |
| 種子 | 11、29、42、73、101；全部保留，不因結果增刪或挑最佳種子 |
| 模型輸入 | 原101，或只加主賣家90天未觀測交運待件等待時齡p90的102；不一起加件數 |
| 唯一參數變因 | `colsample_bytree`由0.8改為1.0，讓每棵樹可使用全部欄位 |
| 其他樹／排序設定 | L2＝100、native topk10、subsample＝0.8、400樹、depth4、learning rate0.05、min child weight10、hist及其餘完整參數不變 |
| 訓練與前處理 | 原核准時點、deadline答案時鐘、wait0、成熟身分／labels／順序／每日query；原train-only補值、OHE與缺失指示不變 |

| 答案截止與保留期間 | 12個原phase保留各fold實際送達答案截止；特徵／評分限2018-05-01之前，原保留測試不重評 |

先保存不可覆寫規格，才新增1.0的8個唯一月份×2組特徵×5種子＝80次fit。0.8沿用前輪80份模型與640,560列凍結帳本，模型只核對雜湊，不載入、重播或重訓；來源帳本逐欄對帳。兩端在相同種子、相同月份身分配對，不把舊結果描述成本輪新訓練。

原101為93數值＋8類別，時齡102為94＋8。原補值器的`add_indicator=True`沿用，時齡欄可再產生自動缺失指示；沒有手動新增指示或變更前處理規則。

## 事前固定的四個對照與穩定性定義

每個種子、phase都保留四種模型設定：101×0.8、時齡102×0.8、101×1.0、時齡102×1.0，逐一比較：

1. 0.8內的時齡102−101，重現前輪結果。
2. 1.0內的時齡102−101，觀察時齡特徵的成對差異。
3. 原101的1.0−0.8，觀察參數對原特徵的影響。
4. 時齡102的1.0−0.8，觀察參數對時齡特徵的影響。

另在同種子內計算差異的差異：`(時齡102−101)於1.0 − (時齡102−101)於0.8`。TP／FP／FN、召回與提醒等模型指標先在種子內相減，再報全部五個種子的平均、最小值、最大值與負／零／正數；不能拿各模型各自極值相減。補抓、新增漏報及名額交換是各對照自己的非負事件計數，另報五種子平均、範圍與寬度，不對交換事件計算差異的差異或正負分箱。零分母率保留空值。

二月的「穩定」預先拆為：每個模型自身五種子TP／召回範圍，以及時齡102−101的成對差範圍寬度（最大−最小）與方向個數。範圍縮小不等於召回提高，方向一致也可能是一致退步；不依執行結果改定義或自動選方案。最小值與最大值只是這五個種子的實際範圍，不是信賴區間。即使種子相同，不同欄位取樣設定也不保證內部列抽樣逐次相同。

全部真實路線、原R／P／A邊際與八格保留；重點為SP→SC與A＝`24 < 等待時齡p90 <= 72`小時。P沿用22–30天分箱（`21 < 天數 <= 30`），R＝SP→RJ；110仍含缺值、至多24或超過72小時，另拆五個既有時齡分箱。所有切片在完整日排名之後，不另分10%名額。

提醒交換先逐日算群組內`min(移除,新增)`與跨群淨流出入，再加總；路線與RPA是不同分割，不能混搭。新增漏報集合相對每個對照自己的old端，內部以身分比對、公開只保留聯交集／頻率／Jaccard等聚合，不能指認指定訂單互相擠出。

## 實際結果

**二月的五種子波動縮小，但沒有提升辨識能力。** 原101的TP範圍寬度17→6，時齡102為31→8；各模型自身都縮小，並非只有兩模型差距縮小。代價是二月召回均值原101為18.72%→18.54%，時齡102為19.24%→18.18%。1.0內時齡−101平均−3.2TP［−9，+5］、4退1進，不能把較一致的負差當成穩定改善。

三個開發月仍為2017-12／2018-02／2018-04，共18,833單、1,642張延遲、1,845個每日取整名額；每個種子、四種設定都相同。相對0.8，1.0原101合計平均少5.4TP［−13，+2］、4退1進；時齡102平均少10.6TP［−20，−5］、五種子全部退步。1.0內時齡−101平均+0.4，只表示兩端下降後的相對差，不能說改參數有收益。
