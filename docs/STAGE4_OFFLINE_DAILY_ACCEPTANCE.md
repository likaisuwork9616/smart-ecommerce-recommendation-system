# Stage 4：離線交付驗收與全量日資料契約

**目前狀態：研究cohort單日交付已通過；全量日名冊、入庫／版本時鐘與日結證據仍待資料。** 本輪在沒有新來源下，整理[資料交接清單與驗收範本](#data-handoff-kit)，沒有實際資料驗收、訓練、改選或新增效能結論。前輪[全量日資料契約與缺口](#full-day-data-contract)及凍結研究名冊交付均保留，不能據此解除正式通知或模型適用限制。

前輪承接[模型卡與交付清單](STAGE4_MODEL_APPLICABILITY.md)，固定四設定與全部五種子，只讀既有分數驗收來源、日分母、排序、每日10%名額及輸出。沒有載入模型、重新預測、訓練、改選或新增效能結論；取消／結案與承諾版本方向維持[待資料](STAGE4_EVENT_SOURCE_AVAILABILITY.md)。

驗收範圍是**原凍結研究cohort的一個完整核准日**，不是生產系統的全量核准日或當時入庫完成證明。來源與交付契約見[本輪規格](../reports/stage4/daily_delivery_acceptance_specification.json)，實際聚合驗收見[正式結果](../reports/stage4/daily_delivery_acceptance.json)。

## 排序、旗標與未知答案

每組先核對當日全242張ID與精確核准時間、版本／種子唯一性及有限的`[0,1]`凍結排名分數，再按**分數降冪、order_id升冪**排列，名次1至242，前24列提醒。分數是未校準的排名分數，不解讀為個人延遲機率。不得先依路線、答案或高分子集縮小分母。

新名單逐列與原`predicted_delayed`旗標核對。原帳本沒有保存rank，因此不能聲稱「原rank逐欄重現」；本輪驗的是由凍結分數重新導出的排名、原提醒旗標，以及既有日邊界摘要。

evaluation的`known_at_selection`沿原契約全為False，表示該開發資料沒有作為歷史選模答案；**不是本日答案已知／未知的分母**。本輪不解析`outcome_for_metrics`，不算TP、FP、FN、召回、精確率或新路線表現。未知答案不應被提前排除的規則，另外以合成高分未知列與標籤改寫案例驗證，不能把合成測試說成當日實際未知答案的效果。

### 名冊、時間與版本的最低契約

| 面向 | 需交付的欄位／語義與驗收規則 |
| --- | --- |
| 身分與範圍 | `source_system`、來源範圍、不可變`order_id`或可稽核匿名映射、核准事件鍵／修訂號、`eligible_rule_version`。先定義一單一次核准、重核准與撤銷語義；不以最終送達／取消、已知答案、路線、分數或缺特徵篩掉當日核准分母 |

此處分開兩個時點：**t是原研究的每單核准查詢時點；T是日結後凍結名冊、排序與交付的時點。** 在T收到當日完整名冊，不能證明t時已取得歷史特徵；t後才取得的事件或修訂，不得因為最後等了日結就回填t。歷史事件沿原契約要求發生與可得時間均早於t，承諾版本的生效／可得邊界沿[既有雙時間規則](STAGE4_EVENT_SOURCE_AVAILABILITY.md#未來來源的驗收契約與停止條件)。當筆核准與基礎欄位本身的可得邊界需另外證明，不能把當筆核准事件也機械要求發生於自身t之前。

若必要輸入實際在t之後才可用，應標為原核准時點適用性未驗收；現在補到資料不會使當時變成已知，也不能悄悄把prediction_time改成T。若需改為入庫後或其他查詢時點，必須另定任務與驗收，本輪不變更模型或特徵契約。

| 上下游對帳 | 同版上游核准事件數／唯一訂單數、去重／修訂規則、ID集合或校驗與本地持久落盤結果一致；重複、缺漏、衝突與隔離列另外列出，不得藏在N之外 |
| 本地可用確認 | 保存日結訊號收到與可查詢時間、對應資料已入庫的證據及批次驗證結果。job成功、目前查不到新列、檔案末列或最大核准時間都不足以證明全日完整 |
| 晚到／更正與重開 | 不覆寫舊批次；保留新revision、原因、取代關係與是否已交付。需另確認可接受晚到、重開截止、通知去重鍵、已送累計名額、撤回與補送規則；未確認前不自動補送 |

日結要求限定**核准名冊資料流**的完整性，不要求所有物流／付款／取消事件都已跨過日界。其他資料各自仍須滿足t時點特徵的可得與版本契約。即使資料齊備，也不能把上游已close直接當成下游已可用或模型已適用。

### 通過與停止條件

全量交付須先取得上述真實資料與來源語義，核對名冊、雙時間版本及日結；任一缺失就列`pending_data`。四設定與11／29／42／73／101五種子維持並列，同一凍結名冊供全部20組，逐組須有N張有效分數，仍以分數降冪、ID升冪及`K=floor(N/10)`驗收；N<10為0，答案未知仍競爭名額，不借日、不另分路線10%。20個研究情境不代表可送20批通知；同日重跑也不能重新取得一份K名額。

目前全量名冊、核准時可得、版本與日結四面向均為**待資料**，只保留前輪研究cohort交付通過。取得資料契約證據後，還要另驗全核准母體的模型適用範圍、使用方處置與成本；資料驗收通過不會自動解除[模型卡](STAGE4_MODEL_APPLICABILITY.md)的限制。取消／結案與承諾版本方向繼續待資料，不訓練、不新增效能指標或重評保留測試。
