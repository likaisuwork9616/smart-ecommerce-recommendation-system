# Stage 12 V52：相近工作量查詢的既有時間波動

接續 V51，檢查與序位 32／38 工作量相近的其他查詢，是否也出現類似的 V46−V39 增時與跨對波動。這一輪只分析 V47／V48 舊紀錄，先驗收工具並封存選取規則，再依既有證據產生對照比較，不新增實驗、SQL、解碼、訓練或保留測試。前序來源重核會重建 V50 計時，但選取函式只接收工作量；匹配完成後才計算對照的時間比較。

目標序位及資料已在 V50／V51 曝光。本輪先固定對照規則可避免再依增時挑對照，但仍是事後描述，不能稱為新的確認性實驗或未知資料成績。

## 先固定對照選取

兩個目標都從其餘 46 筆選對照，同時排除 32 與 38。先要求選定鄰居數及 `fraction_fallback` 狀態相同，再比較下列六個欄位：

| 分項 | 原計數欄位 |
| --- | --- |
| 去重歷史商品數 | `history_rows_inserted` |
| 正重疊 membership 數 | `sql_overlap_membership_matches` |
| Hash 鄰居池列數 | `neighbor_pool_rows_hashed` |
| 不同約分相似度數 | `distinct_neighbor_similarities` |
| 投票 membership 列數 | `sql_vote_membership_rows_returned` |
| 正票候選商品數 | `positive_causal_candidates` |

每欄對稱倍數為 `max(目標, 對照) / min(目標, 對照)`。兩者皆 0 時為 1，只有一邊為 0 則不可比。以整數 Fraction 比較門檻，不依浮點展示值決定是否入選。

| 規則 | 固定定義 |
| --- | --- |
| 主比較 | 六欄倍數都 ≤1.25（5／4）；即對照各欄為目標的 0.8–1.25 倍，含邊界 |
| 敏感度比較 | 六欄倍數都 ≤1.5（3／2），固定一併呈現；包含主比較所有對照 |
| 入選數量 | 保留所有符合者，不限前幾名；沒有合格者就明列沒有，不放寬補足 |
| 最近者 | 必要條件相同且六欄可比者中，取「六欄最大倍數」最小者；並列全保留。不過門檻的最近者只供距離檢視，不加入時間對照 |
| 額外診斷 | 位元寬度與可用 catalog 集合大小的差異另外揭露，不用於選取；fallback 下 bits 的 0 是特殊標記，不做倍數解讀 |

六欄可能相關，最大倍數只是選取距離，並非把異質工作量相加的成本分數；也不代表其他未列欄位、查詢內容或執行時點都相同。1.25／1.5 是本輪事前固定的描述尺度，不是統計顯著性門檻。

## 時間波動口徑

使用 V50 已封存的逐筆計入時間差：`verification + append excluding commit + in-query commit` 的 V46−V39，正值表示候選較慢。暖機不納入；尾端 commit 不能分攤給查詢。固定列出 V47／V48 各六對及原 CR、RC、CR、RC、CR、RC 順序。

每個目標與每個入選對照都保留六個差值、合計、中位數、最小／最大、全距及 MAD。MAD 是各差值距離該序列中位數的絕對值中位數，未乘校正常數；另列正／負／零次數與 ±1 ms 範圍，CR／RC 各三對分開描述。

同向比較只計兩查詢的差值絕對值均大於 1 ms 的配對，列可比較對數、同向與反向對數；恰 ±1 ms 列為小差值。這只是描述尺度，不能用六對推論顯著性。

每一對先取全部入選對照差值的中位數，再算「目標差值−該對照中位數」，最後才彙整六個結果。不能改成「兩組整體中位數相減」。沒有合格對照時，對照中位數及相減結果均為 null。

六對是相同查詢的重複觀測；兩目標的對照集合可能重疊，不能視為獨立群組。固定查詢順序使目標與對照在不同時點執行，所以它們不是同步控制；相減也不能視為已消除主機負載或其他混淆。

## 驗收與封存

27 項人工測試全通，無失敗、錯誤或跳過，耗時 0.637 秒：匹配工具 12 項、波動統計 10 項、人工入口整合 5 項。驗收只用人工計數與人工差值，不讀原始 `measured.json` 挑對照；涵蓋門檻邊界、同距離全保留、零值、必要條件、空對照、目標排除、時間不影響選取、六對順序、MAD、逐對先取中位數、±1 ms 同向分母、來源與原摘要回核，以及 CLI 拒絕 `--measure`。[驗收收據](../reports/stage12/retailrocket_session_knn_v52_peers_acceptance_20261113.json)

方法與測試綁定 bytes／SHA-256，並固定 V47–V51 五份報告。正式分析先唯讀重建前序結果，再核對 28 份原計時檔及 1,344 筆身分／順序／工作量；選取時相同 48 筆只計一次。公開輸出只含匿名 subset 序位、相對工作量診斷與衍生時間差，不提交原 key、原 ordinal、SQL 列或本機模型。
