本頁保留前輪稽核。後續已完成[時間窗盤點與用途凍結](STAGE5_REVIEW_VALIDATION_WINDOWS.md)，五個較晚窗口均待資料，沒有新訓練或評分；以下數字與當時建議保留原輪紀錄。

本輪先凍結口徑，再核對H60完整角色的成熟先驗、未知／未成熟覆蓋及時間差。**29項合成測試與7,134項獨立對帳通過；沒有訓練、讀取個體分數、校準或更新參數。** 固定近期窗口的先驗差沒有跨月一致方向，因此保留原四欄與全部合格歷史對照，暫不指定新的訓練單因子。

核對的是既有快照下的事件時間代理：`核准+60天<fit`，合法首答已在fit前可見。**原業務入庫、評分修訂版本與全量母體的證據仍未補齊，不能把本輪通過寫成營運當下可得性已證明。**

合成檔案測試因既有Windows沙箱tempfile ACL限制，以允許存取專案.runtime的環境執行，沒有放寬斷言或跳過。私有執行、來源快照與獨立對帳留`.runtime/stage5_mature_prior_*`；新guard在`.runtime/stage5_review_mature_prior_v1/input_guard.json`。

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_review_mature_prior_audit tests.test_audit_review_mature_prior -q
.\.venv\Scripts\python.exe scripts\audit_review_mature_prior.py --specification-only
.\.venv\Scripts\python.exe scripts\audit_review_mature_prior.py
```

先凍結新規格／guard再稽核；同版僅接受相同bytes。缺原Olist、H60角色或既有來源證據即停止，Git clone不足，不能補訓練、重寫guard或用其他截止標籤代替。本入口不讀分數值；原訓練／消融及先前診斷CLI都不必重跑。

## 單因子決策與下一步

**保留原四欄、全部合格歷史對照；不選近期窗口、不加先驗／截距修正，也不縮短H60。** 月份間的率差方向反轉，且最近60天缺合格H60標籤；現有證據不足以指定一個跨月適用的先驗修正。這項方向先停在已完成的描述稽核，不直接追加訓練。

下一步建議先盤點尚未用於選模的時間窗與其H60觀察截止、標籤及版本支援，再凍結後續驗證用途；若支援不足就列待資料。避免在同三個已看開發月反覆挑窗口或校準公式；本輪尚未建立新資料集、檢視新測試答案或提出可宣稱改善的效能。

成熟未知／未回覆者缺y，回覆者先驗不能代表全核准母體；跨fit角色與近期窗重疊，不是獨立實驗。原入庫、評分版本、上游全量與時區證據缺口不變。Stage 4待資料、每日10%與五種子維持，Dashboard暫緩。
