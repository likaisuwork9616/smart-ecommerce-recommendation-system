# 回訪者首頁的換榜規則

首輪正式驗收比較「純熱門榜＋留席」與「共同瀏覽優先、熱門補滿＋留席」。**只有獨立名冊同時通過三項門檻，回訪者首頁才採用共同瀏覽留席榜。** 目前公開首頁沿用原熱門瀏覽榜，正式驗收待獨立名冊，九月保留測試繼續封存。

## 三項換榜門檻

以下差值一律取「候選減基準」，在同一批回訪者上計算，以未四捨五入的數值判定。

| 指標 | 正式採用條件 | 訂定依據 |
| --- | --- | --- |
| 前十名命中率差 | **至少 +2.00 個百分點**，相當於每 1,000 位回訪者淨多命中 20 人。 | 七、八月分別為 +3.233、+3.053 個百分點。 |
| 命中率差的成對 95% 區間 | **下限嚴格大於 0 個百分點**。下限恰為零，這項就未通過。 | 七、八月下限分別為 +2.980、+2.824 個百分點。此條件檢查觀察到的優勢能否與零區分。 |
| MRR@10 差 | **至少 +0.010**，以全體可計分回訪者的首次命中倒數名次計算。 | 七、八月分別提高 +0.01809、+0.01607。這項要求候選也在考慮名次後取得改善。 |

兩項改善幅度是採用標準。以改善較小的八月為參照，+2.00 個百分點和 +0.010 分別要求保留約 66% 和 62% 的開發增益。七月淨增 692 人、八月淨增 695 人，依兩月分母換算門檻，分別至少需淨增 429 人和 456 人。兩月都達到這三個數值，但七月資料曾用於八月模型訓練，正式判定只使用另行授權的獨立名冊。[七月開發報告](../reports/mainline/recommendation_july_returning_home_paired_slots_20261127.json) · [八月開發報告](../reports/mainline/recommendation_august_returning_home_paired_slots_20261127.json)

## 首輪固定的兩個版本

採用八月回測使用的同一份熱門瀏覽統計及 C1 共同瀏覽模型。兩者都只用 2015-05-04 至 2015-08-01 零時前的訓練資料（UTC）。核對熱門前十的商品、名次與次數指紋，以及 C1 研究版本的配對、商品支持次數與熱門統計檔指紋。把版本和指紋記入正式報告，全窗使用同一快照。每人的上次瀏覽商品則取自**正式評分窗開始前**的歷史。[熱門榜指紋](../reports/mainline/recommendation_home_first_view_acceptance_august_20261124.json) · [C1 模型收據](../reports/stage10/retailrocket_c1_p0_v1_research_release.json) · [八月使用的雙榜程式](../scripts/evaluate_august_returning_home_paired_slots.py)

| 角色 | 留席前怎麼排 |
| --- | --- |
| 基準（純熱門榜） | 依訓練期有效瀏覽次數由多到少取十件，同分時商品編號小者在前。 |
| 候選（共同瀏覽優先、熱門補滿） | 依訓練期與上次商品共同出現的瀏覽段數由多到少排。同一訪客相鄰瀏覽相隔超過 30 分鐘才分段，一對商品每段只計一次。同分時先比熱門瀏覽次數，再依商品編號由小到大排。照原熱門榜的順序補足十件，跳過重複商品。無共同配對就用完整熱門榜。 |

**兩榜各自留席。** 上次看的商品已在該榜前十就保留原名次，缺席才換掉該榜第十名。窗前已有有效瀏覽的商品具有留席資格，即使缺少訓練配對也能換入。先前只有加購或購買的回訪者，兩榜都給原熱門榜，照常計入分母。每張榜單都須有十件相異商品。

## 獨立名冊到位後如何逐人計分

1. **鎖定評分窗。** 查看命中前，登記獲准的資料來源、用途、版本、UTC 起訖 `[T, U)`、商品鍵對照、名冊人數和檔案指紋。正式窗須在模型截止後，且與訓練、七八月開發及九月封存資料分開。一次評完整窗口，使用這一版門檻。
2. **固定回訪者與上次商品。** 同一匿名訪客在 `T` 前有過有效瀏覽、加購或購買，且在窗內有瀏覽，就納入一列。記錄可核對的窗前行為證明、最後瀏覽的 UTC 毫秒與商品鍵。最後一個時刻看了多件時，取數值編號最小的商品。已確認無窗前瀏覽者可留空，窗內無瀏覽的回訪者另列人數。若歷史不足以區分「沒有瀏覽」與「資料缺失」，或需要開啟封存資料才能補足，整輪記為待驗。
3. **為同一人產生兩個名次。** 先依窗前資料產生兩張榜，再對照該人窗內最早瀏覽時刻看到的所有相異商品。保留同毫秒多件及未出現在訓練目錄的目標。任一件進榜即命中，取最前名次 `r`，未中記空。兩榜共用相同的訪客、商品鍵與目標集合。核對唯一訪客鍵、UTC 時刻與人數，保存名冊和逐人雙榜名次的指紋。
4. **計算命中率差。** 記兩榜皆中為 B、只有候選中為 G（新增）、只有基準中為 L（失去）、皆未中為 M。完整分母 `N = B + G + L + M`。基準命中 `B + L` 人，候選命中 `B + G` 人，淨增 `G − L` 人。命中率差為 `100 × (G − L) / N` 個百分點。用整數比較 `50 × (G − L) ≥ N` 判定第一項。
5. **估計成對 95% 區間。** 按匿名訪客鍵的字串順序排列。每次有放回抽 N 位，同一索引同時帶入該人的兩榜結果，重算命中率差。沿用 NumPy PCG64、種子 20261120，重抽 2,000 次，取 2.5 與 97.5 的線性百分位數。以這個差值區間的原始下限判定第二項。[既有成對重抽樣函式](../scripts/score_recommendation_acceptance.py)
6. **計算 MRR@10 差並判定。** 每人命中得 `1/r`、未中得 0。兩榜各對全部 N 人取平均，再相減。等於 +0.010 即通過第三項。需要精確判等時，可將每個名次換成整數權重 `2520/r`，未中為零，檢查 `100 ×（候選總權重 − 基準總權重）≥ 2520 × N`。

正式報告列出全體四種命中人數、各榜命中率與 MRR@10、三項指標的差值或區間及各自判定。另列有共同配對、有上次商品但無配對、無歷史瀏覽三組的人數與結果，方便解讀增益來自哪裡。採用與否依全體判定，逐人資料留在本機，公開報告僅放彙總與核對指紋。

| 獨立驗收狀態 | 首頁決定 |
| --- | --- |
| 名冊與兩榜核對完成、N 大於零，三項全數通過 | 回訪者首頁可採用共同瀏覽留席榜。 |
| 可完成計分，但任一門檻未達 | 沿用目前公開首頁的原熱門瀏覽榜。 |
| 獨立名冊未到、N 為零，或資料與榜單無法核對 | 記為待驗，首頁沿用原熱門瀏覽榜。 |
