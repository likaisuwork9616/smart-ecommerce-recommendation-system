全月規劃截止採`下月月初+60 elapsed days`：若核准t位於完整月內，則t+60天嚴格小於這個界線。這是足以涵蓋整月的規劃日期，不是已證實的實際觀察截止，也不隨最後一筆可見訂單縮短。

原C=2018-07-01只讓5月406張時鐘滿H60，尚有6,660張未滿；6–9月均0張滿。即使5月部分列可成熟，仍在既有核准cohort之外，不能用這406張替代完整5月驗收。

原檔最大回答時間為2018-10-29 12:27:35，最大評論建立時間為2018-08-31。5–7月的規劃界線早於部分可見回答事件，不證明其他訂單都已完整觀察；8月、9月的全月規劃截止甚至超出最大回答時間。9月僅1張有效核准單，無全月涵蓋證據，也不可能單憑一張單證明二元類別支援。

可連評論metadata只表示有來源列／時間戳，不表示首答在窗內、score合法、可形成H60標籤或沒有未知。新窗口的首答品質、評分類別支援與完整角色未驗收，本輪保持未定，沒有把缺列或未回覆當成0。
