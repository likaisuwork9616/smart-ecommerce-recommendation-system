# Stage 4：核准當下成熟歷史路線／賣家訊號稽核

承接[四模型共同漏報與每日邊界](STAGE4_FOUR_MODEL_BOUNDARY.md)，固定原101／時齡102 × colsample 0.8／1.0與11、29、42、73、101五個種子，沿用完整核准日10%提醒。本輪先重建成熟送達歷史，再查三個未直接使用過的候選；沒有新增訓練、模型重播、提醒政策或主方案選擇。

**20個既有成熟歷史欄位重算一致，但本輪尚不足以選定新的單因子訓練。** SP→RJ共同漏報與準時件的賣家CDF及賣家×路線延遲率很接近；等待組的joint歷史多數少於20筆，易受路線先驗主導。近期30天率差雖較少與原欄位相關，其群組方向隨月份變化，不能把它當成已證明的新風險訊號。這是可得性與診斷的負結果，沒有證明三者在任何模型都無效。

## 原訊號重建與三個事前候選

重算20欄包含global／seller／route的件數、平滑延遲率、小數天平均耗時、route日曆p50／p90與目前承諾CDF、promise margin／ratio，以及相對global延遲率。全1,416,880個原欄值與凍結快取一致，缺失位置相同、最大絕對差0；其餘原欄也不變。新快取只在原138欄後加3個候選及34個支援／先驗稽核欄，175欄逐筆資料維持Git忽略。

| 事前候選 | 定義 | 與現有欄位的差別 |
| --- | --- | --- |
| `seller_promise_cdf_90d` | 同seller成熟日曆耗時≤本單目前承諾的件數，加20筆當時global CDF先驗，再除以seller件數＋20 | 原來只有route CDF；seller歷史延遲率是各舊單自己的承諾，平均耗時也不能還原此CDF |
| `seller_route_delay_rate_90d` | joint seller×state-route的成熟延遲件數，加20筆當時route90率先驗，除以joint件數＋20 | 原來是seller與route各自邊際率及類別，未直接加入joint率 |
| `route_recent30_delay_rate_excess90d` | route成熟30天延遲率（20筆global30先驗）減route成熟90天率；global30先用20筆0.05先驗平滑 | 不同於既有7／14天核准量與逾期待件變化，也不同於單一90天率 |

所有先驗強度均事前固定20；global90延遲率沿用20筆0.05先驗。未知seller／route不合成新群組，候選缺失、支持0；已知但沒有本地歷史可退先驗，不能當成本地證據。全域無歷史時CDF缺失，率仍可能有先驗值。新CDF使用正規化日期間的日曆天，與目前承諾同單位；舊平均耗時則仍是小數天。

30天包含於90天，不能當兩批獨立樣本；route30支持0時也可能因global先驗不同而有非零差值。這些CDF／率是**被觀測到完成的歷史分布**，不是已校準的本單未來送達機率。

如果條件比較形成一致且有支援的差異，下一輪另凍結單因子訓練規格，以101×0.8加單一欄、原前處理／成熟訓練時鐘、五種子及完整日10%成對比較，全部報整體與R／A／RA／SC代價。不把支援件數一起偷偷加入，也不改colsample、預算或挑最好種子。這些後續比較與新fit尚未執行。

## 重現與限制

使用既有`.venv/`、既有原始CSV及前輪凍結帳本，不需新套件、下載或MySQL。此規格只對專案預設`data/raw/olist`來源與其已驗證SHA有效；請沿用以下預設指令。程式內部的非預設`--raw-dir`不屬本規格驗證範圍，替代資料來源需另行綁定實際讀入的SHA。

```powershell
.\.venv\Scripts\python.exe scripts\audit_mature_history_signals.py --specification-only
.\.venv\Scripts\python.exe scripts\audit_mature_history_signals.py
.\.venv\Scripts\python.exe -m unittest tests.test_delay_mature_history_audit tests.test_delay_mature_signal_profiles tests.test_audit_mature_history_signals -v
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

規格、正式報告及cache只允許相同內容重現，不覆寫不同產物。若另輪重現，使用新的`--specification`、`--output`與Git忽略`--cache`路徑。Windows受限環境的完整測試需要允許Python暫存目錄與本機執行緒管線；本輪在具備該權限的環境完整通過。

完整數字見[事前規格](../reports/stage4/mature_history_signal_specification.json)與[成熟歷史訊號稽核](../reports/stage4/mature_history_signal_audit.json)。本輪只驗證目前資料與事件時間假設下的可重現性及剖面，未驗證實際入庫可得性、因果或新候選的未知資料成績。
