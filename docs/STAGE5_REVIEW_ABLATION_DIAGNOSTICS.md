# Stage 5：三欄與四欄凍結分數的只讀配對診斷

本輪完成逐月機率、排序差異及星期／小時／等待支援診斷，**沒有fit、transform、predict或重新選C**。三欄多數分數向下移；12月、2月原本的平均低估加深，4月高估縮小。各月排序高度相關，星期／小時整體有足夠歷史支援，損失差也不只集中在等待尾部。**本輪決策：保留四欄凍結對照，不指定下一個訓練單因子。**

## 範圍與凍結方法

[事前診斷規格](../reports/stage5/review_ablation_diagnostic_specification.json)先於真實統計產生；[聚合結果](../reports/stage5/review_ablation_diagnostics.json)與[驗證報告](../reports/stage5/review_ablation_diagnostic_verification.json)另存新版本，原分數、訓練程式與報告不變。這些月已檢視，僅描述既有開發分數；不評估新holdout、不重選參數或提醒門檻。

## 單因子決策與下一步

**保留原四欄對照，本輪不指定新的訓練單因子。** 移除月份只改善部分內層機率水準，外層AP並未改善；星期／小時沒有普遍零支援，不能以此支持直接刪欄。等待右尾偏移存在，但損失差廣泛分布，沒有足夠證據直接換log或clip；本輪也沒有證明類別權重、校準或門檻調整有益。

下一步建議先凍結「各fit當下可得的成熟低評先驗與時間漂移」只讀稽核，沿用相同角色與H60，比較合格歷史先驗及查詢月的已知低評率，將未知／未成熟覆蓋另列，再判斷是否值得提出一個過去資料可計算的修正規格。這只是下一步建議，尚未實作新特徵、校準或訓練；外層已知低評率只能診斷，不能回填當時參數。

固定窗回覆者的條件目標、未知者無y、歷史角色重用與原入庫／評分版本／上游全量缺口不變。Stage 4繼續待資料、每日10%與五種子；Dashboard暫緩。
