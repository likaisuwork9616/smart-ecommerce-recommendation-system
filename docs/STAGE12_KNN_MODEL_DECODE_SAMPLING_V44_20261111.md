# Stage 12 V44 Model 解碼低頻抽樣

V43 逐次計時的配對差中位數為 +0.737 秒。V44 用低頻計時重測字串掃描與陣列解析的相對成本。每 64 個 256 字元區塊為一層，每層以固定種子隨機選一個區塊，依字串起點或陣列結束位置判定是否計時。尾層按實際區塊數加權。每個區塊的計時和呼叫數依抽中機率反推全量。

| 項目 | 方法與驗收 |
| --- | --- |
| 字串掃描與 tuple | 計時選中區塊的原 `_string` 和 `tuple`，在區塊邊界切換函式。字串跨過區塊時依起點歸屬 |
| 陣列解析 | 用同一對原版總時間扣除抽樣估計的字串、tuple 及單次 UTF-8 時間。餘額包含標記判斷、堆疊與元素加入等原解析迴圈工作 |
| 計時開銷 | 每臂一暖機，八對交替執行原版與抽樣版。配對淨差涵蓋區塊判斷、計時和當時環境波動。另以相鄰讀錶間隔的中位數試算排名敏感度 |
| 工具驗證 | 4 項測試通過，驗證區塊起點、跨越區塊、尾層權重、字串及錯誤處理一致性，以及配對估算 |
| 人工開銷校準 | 人工 canonical 1,004,462 bytes，18 次輸出一致。八對原版／抽樣版中位數 0.402／0.440 秒。配對淨差中位數 +52.4 毫秒（+14.7%），範圍 −115.0 至 +142.0 毫秒，6／8 對抽樣版較慢 |

人工校準的相鄰讀錶中位數為 100 ns。真實重測核對 V43 的 SHA-256、完整 tuple 結構與呼叫數，開銷採真實窗口自己的配對差。

## 同一份 model 的八對結果

**這批配對整體顯示字串掃描較慢。** 字串在 7／8 對較慢，逐對的「字串減陣列」差值中位數為 **+0.219 秒**。以下各分項獨立取中位數。

| 分項 | 中位數（秒） | 八對範圍（秒） |
| --- | ---: | ---: |
| 原版整段 | 1.895 | 1.668–2.144 |
| 抽樣版整段 | 1.909 | 1.644–2.384 |
| 字串掃描，抽樣加權估計 | 0.967 | 0.849–1.212 |

UTF-8 解碼在抽樣版每次直接量一次，中位數 0.001263 秒。每次實際計時中位數為 9,333.5 次字串呼叫與 6,223 次 tuple 轉換，分別約占原版 596,879 與 397,924 次的 1.56%。加權呼叫數中位數為 596,698 與 397,835。用每對的原始精度計算，抽樣版淨差中位數為 +55.2 毫秒（+2.93%），範圍 −162.2 至 +240.5 毫秒，6／8 對抽樣版較慢。

把本輪相鄰讀錶中位數 100 ns 從每次字串與 tuple 的估計扣除，再重算陣列餘額後，字串仍有 6／8 對較慢，整體差值中位數縮到 +0.060 秒。未扣除時，兩種順序的中位數都顯示字串較慢。扣除後，原版先跑的四對中位數變成 −0.014 秒，抽樣版先跑的四對為 +0.115 秒。這項敏感度試算反映了估算對時鐘開銷和配對順序的依賴。若要據此選擇優化項目，可先分開量 `_string` 的字元檢查與 `scanstring`，再用原版整段解碼確認效益。

18 次解碼的 tuple 結構與編碼深度核對通過。`--audit model` 已重建原版結構、核對 V43 同來源描述符，並從保存的區塊計數及配對時間重算摘要。查詢與 fit 各 0 次。
